# Автоматическое обновление Sitemap

## Что сделано

### 1. Генератор sitemap (`src/utils/sitemap-generator.ts`)
Утилита для автоматической генерации sitemap.xml на основе:
- Статических страниц (главная, FAQ, блог, и т.д.)
- Всех статей блога из `src/data/blog-posts.ts`

### 2. Кнопка скачивания в админ-панели
В `/admin` добавлена кнопка **"Скачать Sitemap"** для быстрого получения актуального sitemap.xml

### 3. Скрипт обновления (`scripts/update-sitemap.js`)
Node.js скрипт для автоматического обновления `public/sitemap.xml` перед сборкой проекта.

## Как использовать

### Скачать актуальный sitemap через админку:
1. Зайти в `/admin`
2. Нажать кнопку **"Скачать Sitemap"**
3. Файл `sitemap.xml` скачается автоматически

### Обновить sitemap перед сборкой (вручную):
```bash
bun run sitemap
```

### Автоматическое обновление при сборке:
Добавьте в `package.json` (если это возможно):
```json
{
  "scripts": {
    "build": "node scripts/update-sitemap.js && vite build",
    "sitemap": "node scripts/update-sitemap.js"
  }
}
```

## Как работает

1. При добавлении новой статьи в `src/data/blog-posts.ts`
2. Генератор автоматически подхватывает её в sitemap
3. При скачивании через админку или запуске скрипта — sitemap обновляется со всеми новыми статьями
4. Даты последнего изменения берутся из `dateModified` или `datePublished` статьи

## Преимущества

✅ Автоматическое включение всех статей блога
✅ Актуальные даты последнего обновления
✅ Удобный интерфейс в админке
✅ Можно обновлять перед каждым деплоем
✅ Поддерживает приоритеты и частоту изменений для каждой страницы
